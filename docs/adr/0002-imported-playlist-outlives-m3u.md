# Импортированный M3U-плейлист живёт после удаления своего файла

Обычные плейлисты импортируются из M3U-файлов в Documents автоматически при
сканировании (добавление и обновление порядка), но удаление или пропажа
M3U-файла не удаляет импортированный плейлист — он остаётся, пока пользователь
не удалит его сам.

Причина: M3U-файлы — одноразовый источник при переносе с мака; удалённый или
перемещённый файл не должен сносить плейлист с выстроенным порядком. Trade-off
в пользу стабильности плейлиста вместо зеркального отражения файловой системы.
