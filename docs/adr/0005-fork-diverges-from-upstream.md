# Форк разошёлся с апстримом; upstream держится подключённым

`main` этого форка — одиночный squash-импорт апстрима `kushalpandya/Petrichor`
на дату форка. Дальнейшего автоматического мержа апстрима нет: форк живёт
своей жизнью (iOS-порт, локальные фиксы), и обратный мерж не планируется.

Причина держать `upstream` подключённым — не синхронизация, а **разбор**:
когда апстрим выпускает изменения, их можно посмотреть и выборочно
использовать (треугольный мерж, cherry-pick, сравнение) с известной точки
отсчёта. Без remote любое сравнение начинается с ручного добавления.

Remote не версионируется, поэтому команда воспроизводима:

```bash
git remote add upstream https://github.com/kushalpandya/Petrichor.git
```

Проверка: `git remote -v` показывает `origin` (форк `speech115/Petrichor`) и
`upstream` (`kushalpandya/Petrichor`).
