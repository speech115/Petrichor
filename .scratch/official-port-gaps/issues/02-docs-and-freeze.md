# 02 — README-iOS, заморозка спеки, ADR о расхождении, upstream remote

Status: resolved

## Проблема

`README.md` — апстримный, iOS-порт в нём не упомянут ни словом. Спека
`docs/superpowers/specs/2026-08-05-petrichor-ios-design.md` разошлась с кодом
(обещает вкладку «Папки» и рамку Home · Media · Folders · Search; в коде —
Home · Discover · Playlists · Search, папок нет), а правило CLAUDE.md
объявляет расхождение дефектом кода — по утверждённому решению устарела именно
спека. Upstream remote не подключён: `git remote -v` показывает только
`origin` (форк), и если апстрим выпустит версию, взять её будет неоткуда.

## Что сделать

**1. `README-iOS.md`** в корне: что это (порт macOS-плеера на iPhone, один
проект, два таргета), требования (Xcode 26.6, iOS 26.1+), команды сборки и
тестов из CLAUDE.md, как переносится библиотека (кратко, ссылка на
`docs/adr/0003-library-copied-from-mac.md`), ограничения (подпись бесплатным
Apple ID — 7 дней, без iCloud; FLAC не играет — AVFoundation), происхождение
(форк kushalpandya/Petrichor, MIT). Три скриншота из симулятора — Home,
Now Playing, Playlists — в `docs/assets/ios/`, снять через симулятор
(инструмент `screenshot` из xcodebuildmcp; библиотеку засеять фикстурами из
тикета 01 или вручную). Скриншоты — единственные допустимые бинарники.

**2. `README.md`**: одна строка-ссылка на `README-iOS.md`, минимальный дифф.

**3. Заморозка спеки**: в шапку спеки добавить блок «Статус: заморожена
(2026-08-09) — исторический документ решения на дату; живое состояние
описывают `CONTEXT.md` и код» и строку «Папки: на iPhone не реализованы,
вкладки — Home · Discover · Playlists · Search; см. `.scratch/two-tab-layout/`
и `.scratch/interface/`». Текст спеки не переписывать.

**4. CLAUDE.md**: абзац «Канон дизайна: … Расхождение кода со спекой — дефект
кода» заменить на: спека — замороженный исторический документ, живой канон —
`CONTEXT.md` + ADR.

**5. ADR `docs/adr/0005-fork-diverges-from-upstream.md`**: форк разошёлся
(`main` — одиночный squash-импорт, обратный мерж не планируется), upstream
remote держится подключённым для будущего разбора. Выполнить:
`git remote add upstream https://github.com/kushalpandya/Petrichor.git` и
записать команду в ADR (remote не версионируется — команда должна быть
воспроизводима).

## Критерии приёмки

- [x] `README-iOS.md` существует, скриншоты лежат в `docs/assets/ios/` и
      отображаются в рендере GitHub.
- [x] Дифф `README.md` — одна строка.
- [x] Спека несёт статус «заморожена» и строку про Папки; остальной текст
      нетронут.
- [x] CLAUDE.md больше не объявляет спеку живым каноном.
- [x] ADR 0005 существует; `git remote -v` показывает `upstream`.
- [x] Оба таргета собираются (докосмические изменения, но CI обязателен).
