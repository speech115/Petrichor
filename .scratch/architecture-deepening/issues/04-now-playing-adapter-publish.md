# 04 — Now Playing публикация в адаптере

**What to build:** Одноразовая публикация Now Playing на iOS заменяется
пере-публикацией на собственных событиях адаптера.

Сейчас `AVQueuePlayerBackend.setNowPlayingMetadata` (:616) публикует один раз;
на паузе/возобновлении/сике лок-скрин экстраполирует из устаревшего якоря
(на маке Crescendo сам якорит elapsed/rate из часов движка). Адаптер
подписывается на собственные события (`timeControlStatus`, seek) и
пере-публикует метаданные сам — менеджер вручную не зовёт.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Пауза, возобновление и сик пере-публикуют Now Playing на iOS
- [ ] Публикация — ответственность адаптера, PlaybackManager не дёргает её вручную
- [ ] Тест шва в `QueueBackendTests`: «пауза пере-публикует метаданные»
- [ ] Лок-скрин показывает корректный прогресс после паузы/сика на устройстве
