# 03 — Курируемый список плейлистов

**What to build:** `PlaylistSource.pinned` — явный список плейлистов на секцию:
членство, порядок, переименование при показе и собственная обложка.

Нужен потому, что ни членство, ни порядок из имени не выводятся: «Любимые
треки» — вэкашный экспорт, который об этом нигде не пишет, а порядок владельца
не совпадает с нумерацией экспортёра. Незакреплённые плейлисты добавляются
после закреплённых; `showsOnlyPinned` (Spotify, VK) прячет их совсем — из
вкладки, не из базы, поиск их находит.

Обложки: `PlaylistCover` — настоящая обложка Spotify Liked Songs с их CDN,
обложка Wrapped «Мой топ 2020» оттуда же, знак Shazam, сердце Яндекс Музыки из
их же спрайта. Рисовать знаки кодом по памяти нельзя: так был нарисован
позапрошлый логотип Яндекс Музыки.

**Это временная конструкция.** То же самое лежит в перенесённой маковской базе
как данные (тикет 07) — после проверки список можно ужать до одних обложек.

Спека: `.scratch/player-and-sources/spec.md`, раздел «Playlists — секции по
источникам».
