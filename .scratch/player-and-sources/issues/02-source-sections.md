# 02 — Секции плейлистов по источникам

**What to build:** Вкладка Playlists группирует плейлисты по сервису, из
которого они экспортированы: умные, затем Spotify, VK, Яндекс Музыка, затем
«My Playlists». Принадлежность читается из имени плейлиста (`PlaylistSource`).

Числовой префикс (`05 Spotify - Shazam`) срезается при показе; в базе имя не
меняется, иначе повторный импорт M3U, который ищет по хранимому имени, создаст
второй плейлист рядом.

Знак сервиса — **в заголовке секции, один раз**. Первая версия ставила его в
каждую строку: под заголовком, который уже назвал сервис, это шум, и он отнимал
у строки мозаику, которая строки различает.

Логотипы — официальные векторы в `Resources/Assets.xcassets`
(`logo-spotify`, `logo-vk`, `logo-yandex-music`), template-режим, цвет задаёт
плитка. Знак Яндекс Музыки — «вспышка» из `music.yandex.ru/favicon.svg`, то есть
после ребрендинга 2024 года.

Строкам добавлены вертикальные отступы: при нуле обложки соседних строк
стыкуются в сплошную колонку.

Спека: `.scratch/player-and-sources/spec.md`, раздел «Playlists — секции по
источникам».
