# 04 — Recently Played полкой альбомов

**What to build:** Новый файл `iOS/Home/RecentAlbumsShelf.swift` — горизонтальная
полка **альбомов** крупными квадратами 130 pt.

Сейчас Recently Played на Home — карусель трек-карточек. По правилу спеки
крупный квадрат означает контейнер, а не песню, поэтому полка сводится к
альбомам.

- Источник — `libraryManager.getRecentlyPlayedTracks(limit:)`, который уже
  вызывается в `HomeTabView.load()`. Группировка по `albumId` в памяти, порядок
  сохраняется по первому вхождению, лимит ~10 уникальных альбомов. Треки без
  `albumId` пропускаются.
- Карточка: обложка 130 pt (`ArtworkTile`, `cacheKey` = id альбома), название
  альбома, артист.
- Тап ведёт в существующий `AlbumPage` через `LibraryDestination.album`.
- Заголовок секции — ссылка с шевроном вплотную к слову (общий компонент из
  тикета 06); отдельной подписи «See All» нет.

Побочная выгода: Albums убраны из корня, и эта полка возвращает к ним дорогу
естественным путём.

Группировку делать **не на главном потоке** — `load()` уже гоняет запросы в
`Task.detached`, встроиться туда же.

Спека: `.scratch/two-tab-layout/spec.md`, раздел «Home», пункт 1.

Симулятор с реальной библиотекой: полка показывает альбомы, а не отдельные
