# 08 — Эквалайзер вместо иконки паузы в строке трека

**What to build:** `iOS/Components/TrackRow.swift` помечает играющий трек
иконкой `pause.fill` акцентным цветом справа. Это выглядит кнопкой, которой
нет: тап по строке играет трек, а не ставит на паузу.

Заменить на **три анимированных столбика** — эквалайзер, который читается как
состояние, а не как элемент управления.

- Три полосы разной высоты, `scaleY` туда-обратно, разные фазы, ~1 с на цикл,
  плавное `easeInOut`.
- Анимация идёт только когда `isPlaying`; на паузе столбики замирают.
- Уважать `accessibilityReduceMotion` — при включённом показывать статичные
  столбики.
- VoiceOver: строка играющего трека должна сообщать состояние, как сейчас.

Строка трека переиспользуется библиотекой, поиском, плейлистами и очередью —
правка одна, эффект везде.

Спека: `.scratch/two-tab-layout/spec.md`, раздел «Строка трека».

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

## Проверка

Симулятор: столбики двигаются при воспроизведении, замирают на паузе, не
дёргаются при скролле длинного списка (анимация не должна перезапускаться на
каждом переиспользовании строки).
