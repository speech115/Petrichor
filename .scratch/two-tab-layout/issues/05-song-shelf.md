# 05 — Discover сеткой песен 4×N

**What to build:** Новый файл `iOS/Home/SongShelf.swift` — горизонтальная сетка
песен в четыре ряда, паттерн хит-парадов Apple Music.

- `ScrollView(.horizontal)` + `LazyHGrid` с четырьмя `GridItem(.fixed(...))`.
  Ширина колонки ~288 pt, чтобы край следующей колонки выглядывал и было видно,
  что список прокручивается вбок.
- Строка: обложка 42 pt (`ArtworkTile`, `cacheKey` = id альбома), название,
  артист. Компактнее `TrackRow`: без свайпов и без индикатора воспроизведения —
  это витрина, а не список.
- Тап играет трек в контексте всей подборки, как сейчас делает
  `HomeTabView.play(_:in:)`.
- Заголовок секции — ссылка с шевроном (общий компонент из тикета 06), ведёт на
  существующий `DiscoverView`.

Данные: `libraryManager.discoverTracks`, логика `LMDiscover` без изменений.
Показывать первые ~12 (три колонки по четыре), остальное — за заголовком.

Компонент делать общим: он же понадобится, если позже появится ещё одна секция
песен на Home.

Спека: `.scratch/two-tab-layout/spec.md`, раздел «Home», пункт 2.
