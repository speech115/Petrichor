## Порядок

Три очереди, каждая оставляет собираемое приложение.

| Очередь | Тикеты | Что даёт |
|---|---|---|
| 1 | 01, 02, 03 | Обложки плейлистов, две вкладки, вкладка Playlists |
| 2 | 04, 05, 06 | Home: полка альбомов, сетка песен, финальный порядок |
| 3 | 07, 08, 09 | Шапки, эквалайзер, Now Playing |

## Не заблокированы прямо сейчас

**01**, **02**, **08** — можно брать параллельно.

Дальше: 03 ждёт 01+02; 04, 05 и 07 ждут 02; 06 ждёт 03+04+05; 09 ждёт 07.

## Грабли, о которых спотыкаются

- `LibraryFilterType.genres` и `.years` — **общий enum**. Удаление кейсов
  сломает macOS-таргет: их используют `Views/Home/HomeView.swift`,
  `DMCategoryQueries`, `AutomationEntities`, `Track`, `Album`, `Artist`.
  Удаляются только iOS-точки входа.
- Интерфейс английский: в `Resources/Localizable.xcstrings` есть только `en` и
  `zh-Hans`. Новые строки — на английском, русскую локализацию в этой фазе не
  начинаем.
- `NowPlayingArtwork` лежит в `Views/`, но уже вызывается из `iOS/`. Это
  прецедент, а не нарушение — новый шов заводить не нужно.
- После тикетов 02 и 03 проверять сборку **обоих** таргетов, не только iOS.
