# 07 — Home: плейлисты и карусели

**What to build:** Вертикальный скролл, сверху вниз:

1. **Плейлисты** — 2-колоночная сетка карточек. Смарт-плейлисты (Favorites,
   Top 25 Most/Recently Played) закреплены сверху, дальше пользовательские
   **по алфавиту** (префиксы источников — «ВКонтакте», «Spotify -», «Яндекс» —
   кластеризуются сами). Обложка карточки — **мозаика 2×2** из обложек первых
   четырёх треков; при <4 треках одиночная обложка/цветная заглушка.
2. **Recently Played** — горизонтальная карусель трек-карточек
   (`lastPlayedDate` desc).
3. **Discover** — горизонтальная карусель трек-карточек (50 непрослушанных,
   логика `LMDiscover` без изменений).
4. **Recently Added** — горизонтальная карусель трек-карточек (`dateAdded` desc).

**Трек-карточка** (единая единица для всех трёх каруселей): миниатюра альбома +
название + артист, тап = играть трек. Отдельных «альбомных» карточек не вводим.

Ручное перетаскивание плейлистов — вне фазы.

Спека: `.scratch/apple-music-design/spec.md`, раздел «Home».
