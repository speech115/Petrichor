# 02 — Автоимпорт M3U-плейлистов

**What to build:** Обычные плейлисты импортируются из M3U-файлов в
`Documents/Petrichor-Playlists` автоматически в ходе реконсиляции: новые
импортируются, изменённые обновляют порядок и состав, удалённый или
перемещённый M3U-файл плейлист не удаляет. Названия плейлистов — из имён
файлов без расширения, порядок треков — позиция в M3U. Смарт-плейлисты
(Favorites, Top 25) не трогаются. Обязателен тест разбора M3U на шве: порядок
и числовые префиксы сохраняются, включая переписанные относительные пути.

**Blocked by:** 01 — Мгновенный запуск и фоновая реконсиляция (импорт
триггерится реконсиляцией).

**Status:** ready-for-agent

- [ ] После переноса библиотеки 13 плейлистов появляются сами, без ручных
      операций, с названиями из имён M3U-файлов.
- [ ] Изменённый M3U (другой порядок, добавленные/убранные треки) обновляет
      существующий плейлист.
- [ ] Удаление M3U-файла из Documents плейлист не удаляет; пропавший трек
      остаётся на своём месте в плейлисте.
- [ ] Тест разбора M3U: порядок и числовые префиксы сохраняются, пути
      резолвятся относительно Documents.
- [ ] Смарт-плейлисты не задеты.
