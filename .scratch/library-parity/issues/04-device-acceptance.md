# 04 — Приёмка на устройстве

**What to build:** Полная библиотека переносится на iPhone, приложение
проходит сценарий «как в Petrichor»: все треки, все плейлисты, мгновенный
запуск, подхват изменений.

**Blocked by:** 01, 02, 03.

**Status:** ready-for-agent

- [ ] 2923 трека в библиотеке, без `Unknown Artist`, названия из тегов.
- [ ] 13 обычных плейлистов в исходном порядке с префиксами + 3 смарт-плейлиста
      (Favorites, Top 25 Most Played, Top 25 Recently Played).
- [ ] Запуск мгновенный: библиотека видна сразу; после копирования новых файлов
      через Finder они появляются после возврата в приложение.
- [ ] Discover показывает 50 непрослушанных треков.
