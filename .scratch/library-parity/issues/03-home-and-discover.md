# 03 — Home и Discover

**What to build:** Вкладка «Библиотека» переименовывается в **Home**. В Home
добавляется раздел **Discover**: 50 непрослушанных треков (playCount = 0, без
дублей), обновление раз в неделю. Логика — общая с маком (`LMDiscover` +
`getDiscoverTracks`), пишется только UI. Списки ленивые, с алфавитным
индексом, как остальные категории.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Вкладка называется Home, настройки открываются из её навигационной панели.
- [ ] Discover виден в Home: 50 непрослушанных треков без дублей.
- [ ] Обновление раз в неделю, как на маке; кнопка/поведение принудительного
      обновления не требуется.
- [ ] Мак (таргет Petrichor) по-прежнему собирается и работает.
