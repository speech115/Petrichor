# 01 — Мгновенный запуск и фоновая реконсиляция

**What to build:** Запуск приложения показывает библиотеку из базы сразу, без
ожидания сканирования. Сканирование Documents превращается в фоновую
реконсиляцию по триггерам: запуск, возврат из фона, кнопка «Пересканировать»
в настройках. Реконсиляция начинается с дешёвой проверки изменений
(перечисление имён и mtime) и пропускается, если ничего не изменилось. Полный
скан с прогрессом — только при пустой базе (первый запуск) или принудительно.
Обложки перечитываются и пост-шаги (дубли, нормализация, статистика, чистка)
выполняются только при реальных изменениях.

**Blocked by:** None — can start immediately.

**Status:** resolved
