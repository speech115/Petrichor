# 08 — Вкладка Плейлисты

**What to build:** Вкладка показывает плейлисты со счётчиком треков. Открытый
плейлист показывает треки **в исходном порядке**, с числовыми префиксами из имён
файлов на месте. Плейлист можно создать, переименовать и удалить; M3U
импортируется из «Файлов». Смарт-плейлисты (Favorites, Top 25) видны и
пересобираются правилами.

**Blocked by:** 04

**Status:** ready-for-agent

Порядок — главное требование этого тикета, а не украшение. Пропавший файл делает
трек отсутствующим, но не выкидывает его из плейлиста и не сдвигает соседей;
возврат файла оживляет трек. Это поведение уже реализовано в `PlaylistManager` —
представление не должно его обходить своей сортировкой.

- [ ] Список плейлистов со счётчиками, смарт-плейлисты видны
- [ ] Треки открываются в исходном порядке, префиксы на месте
- [ ] Отсутствующий файл показан как отсутствующий, порядок не сдвинулся
- [ ] Создание, переименование, удаление
- [ ] Импорт M3U из «Файлов»
- [ ] Строка трека — общая из тикета 04, с жестами
- [ ] Плейлист на 250 треков скроллится без рывков на устройстве
- [ ] Ветки `#if os(iOS)` в `Views/Playlists/` удалены, макосборка зелёная
