# 03 — Очередь и тексты панелями поверх обложки

**What to build:** На Now Playing кнопки «Текст» и «Очередь» поднимают панели
поверх обложки — обложка остаётся на экране и остаётся главным элементом.
Не модальные листы, из которых надо возвращаться. Панель убирается тем же
жестом вниз.

Очередь показывает, что играет сейчас и что дальше, строки перетаскиваются для
смены порядка, свайп удаляет из очереди. Текст скроллится; когда синхронизации
нет — показывается просто текстом, без вранья про подсветку строки.

**Blocked by:** 02

**Status:** ready-for-agent

Макошные `PlayQueueView` и `TrackLyricsView` на iPhone больше не используются:
экраны пишутся заново в `iOS/`. Логика очереди и загрузки текстов остаётся в
существующих менеджерах — переписывается представление, не поведение.

- [ ] Панели очереди и текстов написаны заново в `iOS/`
- [ ] Обложка видна, пока панель поднята
- [ ] Перетаскивание строк очереди меняет порядок воспроизведения
- [ ] Свайп по строке очереди удаляет её из очереди
- [ ] Текущий трек в очереди отличим от остальных
- [ ] Тексты скроллятся, отсутствие текста — спокойное пустое состояние, не ошибка
- [ ] Отдельные `.sheet` для очереди и текстов удалены из `ContentView`
- [ ] Ветки `#if os(iOS)` в `Views/Main/PlayQueueView.swift` и в экране текстов
      удалены — iPhone их больше не вызывает
- [ ] Макосборка зелёная после уборки
