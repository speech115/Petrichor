# 07 — Вкладка Поиск

**What to build:** Вкладка Поиск открывает поле ввода и ищет по всей библиотеке
— трекам, артистам, альбомам. Результаты сгруппированы по типу, тап по треку
запускает воспроизведение, тап по артисту или альбому уводит на их страницу.
Пустой запрос показывает не пустоту, а что-то осмысленное; запрос без
результатов — спокойное состояние с самим запросом.

**Blocked by:** 04

**Status:** ready-for-agent
