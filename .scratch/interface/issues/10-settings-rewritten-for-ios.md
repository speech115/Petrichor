# 10 — Настройки заново в iOS/

**What to build:** Настройки открываются кнопкой в навбаре Библиотеки и
показывают ровно то, что перечисляет спека: пересканировать библиотеку, тексты
песен вкл/выкл, фотографии и биографии артистов вкл/выкл, цветовая схема
(светлая, тёмная, системная) с подкрашиванием по цветам обложки, скрывать дубли
треков, «О программе».

Эквалайзер, скробблинг, автосканирование по расписанию и показ технических
данных трека на iPhone не показываются — их там нет.

**Blocked by:** 01

**Status:** done

Макошный `SettingsView` на iPhone больше не используется. Пересканирование —
операция на 2829 файлов: она должна идти фоном с прогрессом и переживать уход из
приложения, а не морозить экран.

- [x] Пункты ровно по спеке, лишние разделы не показываются
- [x] Пересканирование идёт фоном, с прогрессом, прерываемое и возобновляемое
- [x] Смена цветовой схемы применяется сразу

- [x] Макосборка зелёная, настройки на маке не пострадали

Заметки по реализации:

- Новый экран — `iOS/SettingsScreen.swift`; имя `SettingsView` занято макошным
  файлом, который по-прежнему входит в iOS-таргет.
- `ColorMode` вынесен в общий `Utilities/AppAppearance.swift` (светлая/тёмная/
  авто, `apply()` на обеих платформах): и макошный `AppearanceTabView`, и iOS
  читают один ключ `colorMode`. Схема применяется сразу по переключению и
  заново при старте приложения (`PetrichorApp`).
- Пересканирование — существующий `LibraryManager.scanLibraryRoot()` (полный
  обход корня `Documents` с прогрессом через `NotificationManager`); кнопка
  блокируется во время сканирования, прерывание (вылет/уход из приложения)
  возобновляется на следующем запуске — AppCoordinator сканирует корень на
  старте, повторный обход не дублирует уже импортированные треки.
- Ключи те же, что у мака: `onlineLyricsEnabled`, `artistInfoFetchEnabled`,
  `hideDuplicateTracks`, `colorMode`, `useArtworkColors`.
- Эквалайзер, скробблинг, автосканирование по расписанию и технические данные
  трека не показаны.
