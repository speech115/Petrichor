# 09 — Вкладка Папки

**What to build:** Вкладка показывает дерево папок библиотеки так, как оно лежит
на диске — со структурой подпапок по источникам. Заход в папку показывает
вложенные папки и треки, возврат работает. Из папки можно запустить
воспроизведение всего её содержимого.
