# 04 — Библиотека: категории и ленивые списки с индексом

**What to build:** Вкладка Библиотека открывается корневым списком категорий —
Артисты, Альбомы, Жанры, Годы, Все треки. Тап уводит вглубь через
`NavigationStack`, кнопка назад возвращает. Список всех треков держит 2829 строк
без рывков при скролле, справа — алфавитный индекс, которым можно прыгнуть к
букве.

Строка трека показывает обложку, название и исполнителя; играющий трек отличим
от остальных.

**Blocked by:** 01

**Status:** ready-for-agent

Здесь рождается общая строка трека, которую переиспользуют поиск, плейлисты,
папки и очередь — поэтому этот тикет гейтит шестерых. Сделать её сразу
пригодной для повторного использования дешевле, чем размножить четыре похожие.

Макошный `TrackTableView` на iPhone больше не используется: там `Table` с
сортируемыми колонками и `columnCustomization`, а внутри — тридцатистрочная
iOS-ветка, которая и рисует нынешний список.
