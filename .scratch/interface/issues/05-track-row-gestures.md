# 05 — Жесты по строке трека

**What to build:** Свайп по строке трека влево ставит трек следующим в очередь,
свайп вправо добавляет в плейлист, долгое нажатие открывает контекстное меню с
полным набором действий. Жесты работают одинаково везде, где показывается строка
трека — в библиотеке, поиске, плейлистах и папках.

**Blocked by:** 04

**Status:** ready-for-agent

Действия уже собраны в `TrackContextMenu` — переиспользовать, а не описывать
заново. Жест вешается на общую строку из тикета 04, поэтому появляется сразу во
всех списках.

- [ ] Свайп влево — «Играть следующим», с подтверждающей отдачей
- [ ] Свайп вправо — «В плейлист», выбор плейлиста без ухода с экрана
- [ ] Долгое нажатие — контекстное меню из `TrackContextMenu`
- [ ] Жесты не конфликтуют со скроллом и с алфавитным индексом
- [ ] Хаптика по завершении жеста, а не по началу
- [ ] VoiceOver: действия свайпов доступны как custom actions
- [ ] Проверено на устройстве
