# 02 — Now Playing разворотом из обложки

**What to build:** Свайп вверх или тап по мини-плееру разворачивает
полноэкранный Now Playing, и разворачивается он из обложки мини-плеера, а не
выезжает снизу. Закрывается тем же путём — обложка возвращается на своё место.
Жест перехватывается на полпути: если потянуть обратно, экран следует за
пальцем, а не доигрывает анимацию до конца.

Обложка занимает основную площадь. Под ней название, исполнитель, скраббер,
транспорт, шаффл и повтор.

**Blocked by:** 01

**Status:** done

Текущий `.sheet` с `presentationDetents([.medium, .large])` нарушает принцип
anchored origins: путь открытия не совпадает с путём закрытия, и разворачивается
плеер из ниоткуда. Нужен `fullScreenCover` с зум-переходом от
`matchedTransitionSource` на обложке мини-плеера.

- [x] Обложка мини-плеера помечена `matchedTransitionSource(id:in:)`
- [x] Now Playing показывается через `fullScreenCover` с
      `.navigationTransition(.zoom(sourceID:in:))`
- [x] Закрытие идёт тем же переходом обратно, а не отдельной анимацией
- [x] Пружины интерактивные: жест перехватывается и разворачивается в середине —
      системное поведение zoom-перехода (swipe down и pinch, непрерывная
      интерактивность)
- [x] Обложка — доминирующий элемент, скраббер и транспорт под ней
- [x] Шаффл и повтор на экране, состояние читается с одного взгляда —
      `NowPlayingControlsView` с акцентным цветом и индикатором активного
      состояния
- [x] `.sheet` с детентами для Now Playing удалён
- [x] Reduce Motion уважается: при включённом переход не зумит — системное
      поведение `ZoomNavigationTransition`
- [ ] Проверено на устройстве — **отложено до интеграции**: деплой на телефон
