# 07 — Обложка не гаснет при смене трека

**What to build:** При переключении трека обложка плеера переходит со старой
на новую кросс-фейдом, без кадра с плейсхолдером. iOS (мини-плеер, Now Playing)
и macOS (плеер-бар, мини-плеер, Immersive).

**Status:** in review

## Причина

Записи очереди хранятся без обложки. Трек становится текущим без байтов, и
`PlaybackManager` догружает обложку из базы — причём только после того, как
движок сообщит о старте аудио. Все поверхности рисовали `currentTrack.artworkData`
напрямую и на это время (до секунды) показывали плейсхолдер. На iOS сверху
добавлялось декодирование: `ArtworkTile` сбрасывал состояние по `.id` и ждал
декода уже на плейсхолдере.

## Решение

- `Core/NowPlaying/NowPlayingArtworkHold` — чистая логика: держит прежнюю
  обложку, пока у нового трека она грузится; отпускает на плейсхолдер, только
  когда загрузка подтвердила, что обложки нет. Поздняя загрузка для уже не
  текущего трека игнорируется.
- `PlaybackManager.nowPlayingArtwork` публикует это состояние; загрузка
  обложки стартует при принятии трека, а не после старта аудио.
- `CrossfadeArtwork` — общая вьюха: старая картинка остаётся под новой, пока
  новая не декодирована, затем 0.3 с кросс-фейд.
- На экране Now Playing обложка больше не выезжает слайдом (новый тайл
  въезжал пустым), а меняется на месте; заголовок по-прежнему едет.

- [x] Свойства: обложка — всегда текущего трека или удерживаемая настоящая
- [x] Красный прогон на старом поведении
- [ ] Проверка на телефоне и маке
