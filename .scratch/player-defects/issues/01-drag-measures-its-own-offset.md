# 01 — Свайп вниз мерил перемещение по линейке, которую сам двигает

**What to build:** Свайп вниз по Now Playing должен следовать за пальцем
монотонно. Сейчас при плавном перетаскивании экран «мерцает и дублируется».

**Status:** resolved

## Причина

`DragGesture(minimumDistance: 20)` в `iOS/Player/NowPlayingScreen.swift` без
явного `coordinateSpace` мерит `translation` в **локальной** системе координат
той вьюхи, к которой прикреплён. У плеера это `content(in:)` — та самая
поверхность, которую `NowPlayingPresentationLayer` сдвигает по этому же
`translation`.

Замыкание: offset вырос на N → локальная позиция пальца уменьшилась на N →
`translation` уменьшился → offset схлопнулся → на следующем кадре всё обратно.
Амплитуда колебания равна шагу пальца за кадр, частота — частоте кадров. Глазом
это читается как две наложенные копии экрана.

Тот же дефект был у `NowPlayingPanel` — её header едет вместе с панелью, которую
двигает.

## Измерение

Видео симулятора, кадры по presentation order (`fps=60`), верхняя кромка
поверхности как первый тёмный пиксель в левой колонке.

| | верхняя кромка по кадрам | откатов назад |
|---|---|---|
| до | `0, 53, 0, 63, 53, 74, 63, 84, 74, 95, 84 …` | **17** |
| после | `0, 53, 63, 74, 84, 95, 105, 116, 126 …` | **0** |

Контроль: обычный скролл списка тем же пайплайном — монотонный, дублей кадров
нет. Значит колебание принадлежало приложению, а не записи.

Проверенная гипотеза, которая не подтвердилась: `.compositingGroup()` на
поверхности. Снятие его картину не изменило (те же 17 откатов), поэтому он был
убран отдельно и по другой причине — см. ниже.

- [x] `coordinateSpace: .global` в `dismissGesture` плеера
- [x] `coordinateSpace: .global` в `dismissGesture` панели
- [x] Комментарий у обоих жестов объясняет, почему `.global` тут несущий
- [x] Покадрово: 0 откатов назад на медленном свайпе
- [x] `.compositingGroup()` убран — вход и так монтируется за viewport на кадр
      раньше, а полноэкранный offscreen-проход стоил кадрового времени. Вход
      перепроверен покадрово: кромка фона и кромка обложки идут с постоянным
      зазором 17 px, обложка не приезжает раньше
