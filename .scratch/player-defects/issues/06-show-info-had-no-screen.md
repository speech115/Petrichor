# 06 — «Show Info» вёл в никуда

**What to build:** Пункт «Show Info» есть в меню плеера и в меню каждой строки,
но на iPhone не делает ничего.

**Blocked by:** 05

**Status:** resolved

## Причина

Пункт постит `NSNotification.Name("ShowTrackInfo")`. Единственный подписчик —
`Views/Main/ContentView.swift`, то есть макосный. `iOS/ContentView.swift` на неё
не подписан никогда не был.

## Развилка

Либо строить экран, либо удалять пункт. Спека iOS-дизайна экрана сведений о
треке не перечисляет, так что решение продуктовое, а не техническое — вынесено
пользователю. Выбрано строить: у макоси эта возможность есть, приложение
работает с локальными файлами, где битрейт, формат и путь — рабочая информация,
а слой данных (`FullTrack`, `LMQueries.fullTrack(for:)`) уже общий и собирается
под iOS без правок.

Решение записано в `docs/adr/0004-track-info-sheet-on-iphone.md`, канон дизайна
дополнен одним абзацем.

## Реализация

`iOS/Library/TrackInfoSheet.swift` — экран написан заново под телефон, макосный
`TrackDetailView` не переиспользуется (`Views/` — только macOS). `List` с
`LabeledContent`, детенты `.medium`/`.large`, свёрнутая группа «File Details».

Лист поднимается из `iOS/ContentView.swift`, а не из строки или плеера: так один
и тот же экран достаётся и из списка в глубине `NavigationStack`, и с
поверхности плеера, которая этот список перекрывает.

- [x] Экран написан в `iOS/`, `TrackDetailView` не тронут
- [x] `iOS/ContentView.swift` подписан на нотификацию
- [x] Имя нотификации получило константу `.showTrackInfo` в
      `Utilities/Constants.swift`; макосные литералы не переименовывались, чтобы
      не гонять сборку второго таргета
- [x] Проверены оба входа: троеточие в плеере и долгое нажатие по строке
- [x] `.presentationBackground(Color(.systemGroupedBackground))` — на половинном
      детенте системное стекло просвечивало список и обложку, подписи плыли

## Осталось открытым

Экран сведений — только чтение. Правка тегов с телефона не предполагается:
канон переноса библиотеки в `docs/adr/0003-library-copied-from-mac.md` считает
базу маковской.
